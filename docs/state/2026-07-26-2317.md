## Known gaps / follow-ups worth knowing about

- **Rania's AI list is the main remaining gap**: auto-tagging, captions, best-photo, aesthetic
  ranking, sensitive-content detection are all unbuilt. None have a model chosen yet.
- **Video thumbnails depend on a system `ffmpeg` install** — no bundled decoder; falls back to a
  video-camera placeholder icon if ffmpeg isn't on PATH.
- **Chat model performance**: fine in a release build; in `pnpm tauri dev` (debug), a
  `[profile.dev.package."*"] opt-level = 3` override in `Cargo.toml` is what keeps replies at
  ~20–25s instead of ~14 minutes — don't remove it.
- **RAG context is metadata-only** (filename, date, camera, OCR text) — it doesn't yet fold in
  people/place names, so "who's in this photo" style chat questions won't be well-grounded.
- Some Utilities cards are still explicit "coming soon" placeholders in the UI.
